Xometry Actionability Workshop

Custom Modules - LLM Proxy & Guided Determinism

Workshop Date: TBD
Total Duration: ~3 hours
Format: Hands-on Labs

Overview

This workshop extends the standard MuleSoft Actionability Workshop with two custom modules designed specifically for Xometry's SDLC agent initiative (Project Prism).

You'll build production-grade LLM governance controls and deterministic routing patterns that form the foundation of Xometry's 500-person agentic SDLC platform.

Prerequisites

Required: You must complete Module 2: Govern from the standard Actionability Workshop before starting these custom modules. Module 2 covers the foundational LLM Gateway and policy concepts that these labs extend.

Workshop Context

Xometry's engineering org consumes $3M/year in LLM tokens across AWS Bedrock with no attribution, routing strategy, or cost controls. These modules build the control plane to solve those problems.

Workshop Modules

A
LLM Proxy & Cost Control
Build a centralized LLM gateway that provides a single endpoint for your entire engineering org. You'll implement multi-provider routing, semantic intent detection, and per-team token budgets to gain visibility and control over $3M/year in LLM spend.
Duration: ~90 minutes 4 Labs Difficulty: Intermediate

What You'll Build

  • Multi-provider LLM proxy (AWS Bedrock + Google Gemini)
  • Model-based routing to automatically select providers
  • Semantic routing to detect intent and route complex vs. simple queries
  • Token budgets with per-client rate limiting and overage controls

Labs

  • Lab 1 Create the LLM Proxy
  • Lab 2 Model-Based Routing
  • Lab 3 Semantic Routing
  • Lab 4 Token Budgets & Rate Limiting
B
Guided Determinism
Build predictable, auditable agent workflows using guardrails, constrained outputs, and structured decision trees. You'll implement validation layers that ensure agent behavior stays within bounds while maintaining flexibility for complex reasoning.
Duration: ~90 minutes TBD Labs Difficulty: Advanced

What You'll Build

  • Structured output validation with JSON Schema
  • Multi-step agent workflows with guardrails
  • Human-in-the-loop approval gates
  • Audit trails and decision provenance

Getting Started

Before You Begin

  1. Verify you've completed Module 2: Govern from the standard Actionability Workshop
  2. Obtain your Anypoint Platform credentials from your instructor
  3. Verify you have access to the workshop environment:
    • Anypoint Platform org
    • Flex Gateway deployment (agent-network-ingress-gw)
    • AWS Bedrock credentials (provided by instructor)
    • Google Gemini API key (provided by instructor)

Recommended Path

  1. Start with Module A: LLM Proxy & Cost Control
  2. Complete all 4 labs in sequence (Lab 1 → Lab 2 → Lab 3 → Lab 4)
  3. Each lab builds on the previous one, so don't skip ahead
  4. Module B will be available soon
Ready to Start?

Head to Module A: Lab 1 to create your first LLM Proxy.

Learning Objectives

By the end of this workshop, you will be able to:

  • Deploy and configure LLM Proxies on Flex Gateway
  • Implement model-based routing across multiple LLM providers
  • Build semantic routing logic using embedding-based classification
  • Configure token budgets and rate limiting per client application
  • Integrate LLM Gateway observability with CloudHub telemetry
  • Design guardrails for deterministic agent workflows (Module B)
